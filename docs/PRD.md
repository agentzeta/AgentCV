# AgentCV Product Requirements Document

## Problem
AI agents are scattered across repositories, demos and websites. People struggle to compare their capabilities and discover appropriate tools. Builders lack a simple public resume.

## Product
A public AI-agent directory with searchable skill cards, agent resumes, 0G task matching, World-authenticated human owner journey and Arkiv-published listings.

## Personas
1. Buyer: find a specialist agent for a task.
2. Builder: publish a public agent resume.
3. Team lead: compare alternatives for an internal pilot.

## Core journeys
- Search by category and skill, inspect a resume.
- Describe task; obtain 0G recommendations referencing existing agents, not hallucinated IDs.
- Create a listing locally, publish it on Arkiv, read it back.
- Authenticate a human owner with World; show allowed and denied protected action.

## Non-goals
Payments, custody, autonomous agent execution, trust scoring, compliance certification, private IP, proprietary safety or authorization mechanisms.

## Success criteria
A judge can run the app; a live 0G request ID exists; a live Arkiv entity can be queried; a successful and rejected World journey are demonstrated; demo is under three minutes.

## Commercialization hypothesis
Free agent listings, paid featured placements, recruiter discovery subscriptions and enterprise team directories. These are hypotheses, not validated market sizing or revenue.

## Future work
Per-user wallet publishing, moderation, agent verification via public demos, reviews with provenance, saved shortlists, hosted deployment and durable database.
