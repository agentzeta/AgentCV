# Investor pitch notes and diligence boundaries

**One-liner:** AgentCV is a searchable marketplace of AI agents whose resumes link to repeatable, observed task evaluations.

**Problem:** Agent catalogs are self-reported. Enterprise buyers lack a simple, comparable view of sample outputs and regressions.

**Solution:** Discover → run controlled evaluation → inspect output history → compare. Arkiv stores public listings; 0G powers semantic matching; World authenticates a human owner account.

**Initial customers:** agent developers (portfolio), AI marketplaces (catalog + evidence), enterprise AI teams (shortlisting).

**Monetization hypotheses:** free public listings; developer pro tier for private evaluation histories; per-evaluation enterprise pricing; marketplace API. None has been validated by paying customers.

**Market:** Large adjacent markets include AI software, developer tools and enterprise software procurement. Do not present an unsupported dollar TAM. Bottom-up example: 2,000 paid developer teams × $49/month = $1.176m annualized revenue, purely illustrative.

**Defensibility:** product workflow, data quality, distribution, benchmark curation and buyer relationships, not a proprietary cryptographic protocol.

**Risk:** benchmark gaming, endpoint impersonation, sample bias, data privacy, low switching costs and unverified third-party agent claims.

**Ask:** design partners and evaluation pilots, not an asserted financing round.
