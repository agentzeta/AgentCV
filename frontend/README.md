# AgentCV React demo

React 18 + Vite. The Node backend in the parent directory is the source of truth. No secrets are stored in React. For development run `npm install && npm run dev` in this directory and `npm start` in the parent. For the single-server demo run `npm run build:frontend && npm start` in the parent, then visit `/demo`.

The interface shows sample data when the API is unavailable. Sponsor badges report configuration, not completed sponsor qualification. Agent evaluation claims distinguish local independent HTTP execution from self-submission.
